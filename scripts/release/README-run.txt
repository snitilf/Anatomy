Anatomy runs in your browser, on your computer.
You need Node.js 24 or later.

1. Open a terminal in this folder.
2. Run: node serve.mjs
3. Open http://127.0.0.1:4173 in your browser.

For another port, run for example: node serve.mjs 4200
Press Ctrl+C in the terminal to stop.

Chrome or Edge can open a project folder.
Other browsers open a board file or a built-in example.
The app makes no network requests after it loads.
