# Anatomy 0.1.0

Anatomy is a local web app that shows an AI coding agent's explanation of a codebase as an interactive architecture diagram.
This is the first release.

## Run it

You need Node.js 24 or later.

1. Unzip `anatomy-0.1.0.zip`.
2. Open a terminal in the folder it made.
3. Run `node serve.mjs`.
4. Open http://127.0.0.1:4173 in your browser.

Chrome and Edge can open a project folder.
Other browsers open a board file or a built-in example.
To try Anatomy without any setup, open the hosted copy at https://snitilf.github.io/Anatomy/.
It is the same app.

## What is in 0.1.0

- A map that lays itself out from left to right, with lines that route around the cards.
- Big boards that fold into their groups when you zoom out.
- Walkthroughs that play a journey one highlight at a time.
- A source on every claim: said by the user, read by the agent, stated by a plan, or proposed and not yet decided.
- An Overview page, a whiteboard with pen, shapes, text, and notes, and a Review tab with the agent's answers.
- Undo and redo for the last 100 steps, light and dark themes, a command menu, and full keyboard control.
- Three built-in examples: How the Claude Code harness works, Anatomy itself, and How a large language model like Opus 5.5 works.
- The round trip with your agent: **Copy prompt** writes the agent files into your project, the agent writes `.anatomy/board.json`, and **Send to agent** returns your marks as `.anatomy/feedback.json`.
- A board format with a JSON Schema, and a command line tool, `anatomy.mjs`, that checks a board and applies a patch.
- No accounts, no cloud, no telemetry, and no AI inside the app.
  The page makes no network request after it loads.
